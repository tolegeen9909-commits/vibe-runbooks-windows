# 07 · Итоговый чек-поинт

## Зачем

Собрать один понятный итог по базовой среде и выбранным трекам. Невыбранные треки не снижают результат.

```powershell
powershell -ExecutionPolicy Bypass -File .\07-checkpoint\self-check.ps1
```

Проверка строгая: для успеха должны пройти все базовые пункты и все пункты каждого явно выбранного трека. Один пустой обязательный пункт останавливает маршрут.

После успешного результата этот установочный маршрут завершён. Дальше открой `https://academy.adarasoft.com/course/vibecoding` и урок 1.1 «Режим плана (Plan Mode): сначала план, потом дело».
