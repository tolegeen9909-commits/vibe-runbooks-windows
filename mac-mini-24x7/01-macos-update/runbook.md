# 01 · Безопасное обновление macOS

## Результат фазы

Software Update подтверждает актуальную совместимую macOS, а возможная установка завершена при физическом доступе и стабильном питании.

Официальная инструкция: [Apple — Update macOS on Mac](https://support.apple.com/en-us/108382).

## Стоп-условия

Не начинай установку, если:

- нет физического доступа к Mac;
- нет свежей резервной копии важных файлов;
- идёт несохранённая работа;
- питание или интернет нестабильны;
- FileVault password/recovery path неизвестен владельцу;
- Mac управляется организацией и update контролирует администратор.

Recovery key не показывается гиду.

## Шаг 1 · Проверить наличие обновления

Это сетевой запрос к Apple, поэтому нужен отдельный approval-gate.

### Шлюз согласия — сетевой read-only запрос

> **Устройство:** Mac mini.
> **Точное действие:** открыть `Apple menu → System Settings → General → Software Update` и дождаться окончания проверки.
> **Последствие:** Mac свяжется с Apple и покажет только совместимые обновления; установка ещё не начнётся.
> **Проверка:** виден статус «up to date» или конкретное доступное обновление.
> Выполнить именно это действие? Ответьте `да`.

Не нажимай Update, Upgrade или Restart в этом же шаге.

## Если Mac уже up to date

Зафиксируй только факт, что интерфейс не предлагает обновление. Не записывай Apple Account, serial или screenshot с личными данными. Перейди к повторной preflight-проверке ниже.

## Если обновление доступно

Сначала пользователь:

1. завершает резервную копию;
2. сохраняет документы;
3. подключает стабильное питание;
4. остаётся рядом с Mac;
5. закрывает приложения.

Это подготовка, а не разрешение на установку.

### Шлюз согласия — установка и возможный reboot

> **Устройство:** Mac mini.
> **Точное действие:** в уже открытом `Software Update` нажать кнопку с фактическим названием `Update Now`, `Upgrade Now` или `Restart Now` ровно один раз.
> **Последствие:** macOS загрузит и установит пакет; может запросить admin password, несколько раз перезапустить Mac и временно оборвать любой удалённый доступ.
> **Риск и откат:** установку нельзя безопасно прерывать; rollback не считается мгновенной операцией. Физический доступ и backup обязательны.
> **Проверка:** после завершения пользователь локально входит в macOS и снова открывает Software Update.
> Выполнить именно это действие? Ответьте `да`.

Пароль администратора вводится только в системном окне. Гид не запускает update через shell.

## Шаг 2 · Проверить результат

После полного завершения update и локального входа снова выполни read-only preflight:

```bash
bash ./mac-mini-24x7/00-preflight/check-system.sh
```

Затем после отдельного согласия снова открой Software Update и убедись, что обязательных обновлений больше нет. Если предлагается ещё один update, повторяй цикл только после новой проверки backup и нового `да`.

## Необязательная защита

Apple рекомендует автоматическую установку security responses/system files. Если пользователь хочет включить её, это отдельное изменение:

> **Точное действие:** `System Settings → General → Software Update → Automatic Updates → Install Security Responses and system files → On`.
> **Последствие:** Mac сможет автоматически получать системные security files.
> **Откат:** вернуть переключатель в Off.
> Выполнить именно это действие? Ответьте `да`.

Не объединяй это согласие с установкой macOS.

## Checkpoint

Только после подтверждения актуального статуса и успешного локального входа покажи:

```bash
./mac-mini-24x7/scripts/record-checkpoint.sh step 01-macos-update:verified
```

Команда меняет только локальный progress и требует отдельного `да`.

## Готово, когда

- Software Update не показывает обязательное совместимое обновление;
- Mac успешно загрузился и пользователь вошёл локально;
- preflight больше не показывает блокирующую версию;
- записан `01-macos-update:verified`.
