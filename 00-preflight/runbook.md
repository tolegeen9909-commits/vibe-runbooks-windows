# 00 · Проверка Windows перед стартом

## Зачем

Сначала только смотрим на компьютер: версию Windows, разрядность, память, свободное место, виртуализацию и уже установленные инструменты. Скрипт ничего не устанавливает; при успехе он только запишет локальный маркер прогресса.

## Шаг

Открой обычный PowerShell в Windows Terminal и из корня репозитория выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\00-preflight\check-system.ps1
powershell -ExecutionPolicy Bypass -File .\00-preflight\verify.ps1
```

Пустые пункты `[ ]`, кроме `winget`, не являются ошибками. Они показывают, что будет установлено позже.

## Чек-поинт

- Windows 11, 64-bit;
- не меньше 8 GB RAM для базы;
- не меньше 15 GB свободного места для базы;
- `winget` доступен;
- для Flutter желательно 16 GB RAM, 50 GB свободного места и включённая виртуализация.

После зелёного результата переходи к `01-windows-setup/runbook.md`.
