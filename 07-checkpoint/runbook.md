# 07 · Итоговый чек-поинт

## Зачем

Собрать один понятный итог по базовой среде и выбранным трекам. Невыбранные треки не снижают результат.

```powershell
powershell -ExecutionPolicy Bypass -File .\07-checkpoint\self-check.ps1
```

Пороги:

- только база: 5 из 6;
- база + один трек: 8 из 10;
- база + оба трека: 11 из 14.
