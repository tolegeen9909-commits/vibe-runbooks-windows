# Рабочие ритуалы

Эти ритуалы помогают новичку понимать, что происходит, а гиду — не перескакивать через проверки.

## 1. Старт сессии

1. Назови текущую фазу и последнюю завершённую точку из `state/progress.json`.
2. Скажи, что понадобится на ближайшем шаге.
3. Проверь, что терминал открыт в корне репозитория.
4. Дай ровно одно следующее действие.

## 2. Перед установкой

1. Объясни, что устанавливается и зачем.
2. Покажи официальный источник или точный `winget` package ID.
3. Предупреди об UAC, большой загрузке или новом окне браузера.
4. Проверь, не установлен ли инструмент уже.
5. Запусти только скрипт текущего шага.

## 3. После установки

1. Открой новый Windows Terminal, если изменился PATH.
2. Выполни короткую команду версии.
3. Запусти `verify.ps1` текущей фазы.
4. Продолжай только при exit code `0`; ручные предупреждения обсуди отдельно.

## 4. Вход в аккаунт

1. Назови официальный сервис и зачем нужен вход.
2. Получи явное согласие открыть browser login.
3. Пользователь вводит пароль и 2FA только в браузере.
4. После возврата проверь статус отдельной командой, например `gh auth status`.

## 5. Одна ошибка — одно исправление

1. Сохрани точный текст ошибки без секретных данных.
2. Воспроизведи проблему самой короткой read-only командой.
3. Выбери одно минимальное исправление.
4. Повтори именно исходную проверку.
5. Не смешивай несколько гипотез и не переустанавливай всё сразу.

## 6. Commit, push и deploy

Всегда проговаривай разницу:

- **commit** — снимок сохранён только на компьютере;
- **push** — commit отправлен в приватный GitHub-репозиторий;
- **preview deploy** — временная ссылка для проверки;
- **production deploy** — публичная постоянная ссылка.

Перед commit проверь staged-файлы и секреты. Перед push и production deploy получи явное подтверждение.

## 7. Завершение или перерыв

1. Запусти проверку текущей фазы.
2. Убедись, что checkpoint записан в state.
3. Одной фразой скажи, что готово.
4. Одной фразой назови следующий шаг после возвращения.
5. Не проси пользователя повторять уже пройденные фазы.

## 8. Итог маршрута

1. Запусти `07-checkpoint/self-check.ps1`.
2. Исправляй пустые обязательные пункты по одному.
3. После exit code `0` перечисли готовую базу и выбранные треки.
4. Отдельно напомни: Windows не собирает iOS, а production-ссылку нужно беречь как публичную.
