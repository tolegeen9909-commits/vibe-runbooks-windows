# Mac mini 24/7 — главный runbook

## Что строим

Mac mini должен быть доступен для удалённой разработки без публикации SSH в интернет. Каналы разделены:

- **основной:** Windows → Tailscale → обычный SSH → Apple Remote Login на Mac;
- **удобный SSH-клиент:** Termius использует тот же host и SSH-ключ;
- **резервный GUI:** Windows → AnyDesk → Mac;
- **локальное восстановление:** человек у Mac остаётся обязательным для первого reboot/power test и для secure-mode после холодной загрузки с FileVault.

Tailscale SSH server не используется. На роутере не создаются port-forward, DMZ или публичный TCP/22.

## Почему сначала доступ, потом инструменты разработки

Обновление macOS, сон, FileVault и приложения, запускаемые после login, могут оборвать удалённый канал. Поэтому порядок фиксирован:

1. узнать исходное состояние;
2. безопасно обновить macOS;
3. настроить питание;
4. доказать LAN SSH и ключи;
5. добавить резервный AnyDesk;
6. перенести SSH в tailnet;
7. выбрать recovery/security mode;
8. проверить reboot, питание и headless;
9. только затем устанавливать dev tools;
10. выполнить итоговый checkpoint.

Полная карта: [INDEX.md](INDEX.md).

Удалённые фазы 00–08 и dev-фаза имеют разные support boundaries: новый Homebrew-backed setup в фазе 09 поддерживается этим MVP только на Apple Silicon с macOS 15+. Intel или более старая macOS не превращают удалённый маршрут в негодный, но блокируют фазу 09 и final readiness до отдельного проверенного addendum.

## Что маршрут не делает

- не меняет настройки Mac автоматически;
- не отключает FileVault;
- не включает automatic login;
- не выдаёт TCC-разрешения приложению;
- не устанавливает Homebrew, Tailscale, AnyDesk или другие программы скриптом;
- не хранит IP, hostname, username, AnyDesk ID или credentials;
- не выполняет reboot или физический power-cycle;
- не обещает pre-login доступ стандартного Tailscale-клиента macOS.

## Подготовка

До фазы 00 нужны:

- физический доступ к Mac;
- сохранённая работа и актуальная резервная копия;
- Windows-компьютер в той же LAN для первых SSH-тестов;
- стабильные питание и интернет;
- менеджер паролей;
- понимание, кто владелец Mac и tailnet.

Если Mac корпоративный или tailnet общий, изменения access policy выполняет администратор. Шаблон личного tailnet нельзя применять поверх существующей policy.

## Модель угроз

Маршрут защищает от случайной публикации SSH и чрезмерных разрешений:

- SSH доступен только выбранному локальному пользователю;
- сначала используется key authentication;
- доступ по интернету идёт внутри tailnet;
- AnyDesk получает только Screen Recording и Accessibility, если нужен полный контроль;
- Full Disk Access не выдаётся без доказанной необходимости;
- unattended password и 2FA остаются только в локальных официальных интерфейсах;
- FileVault включён в рекомендуемом режиме.

Маршрут не защищает машину, если злоумышленник получил unlocked session, private SSH key, unattended credentials или полный контроль над tailnet account. Поэтому нужны уникальные пароли, 2FA и отзыв потерянных устройств.

## Secure mode по умолчанию

В `secure` режиме:

- FileVault включён;
- automatic login выключен;
- после login пользователя работают Tailscale, SSH и AnyDesk;
- после полного отключения питания FileVault может ждать локальный пароль до старта пользовательских приложений и стандартного Tailscale GUI.

Это ожидаемое ограничение, а не ошибка.

## Autonomous mode только после решения

`autonomous` режим уменьшает риск потерять удалённый доступ после питания, но может уменьшить физическую защиту данных. Решение принимается только в фазе 06 после рабочего SSH, Tailscale и AnyDesk. До физического теста фаз 07–08 статус `autonomous-ready` запрещён.

## Проверки

Read-only scripts используют четыре результата:

- `PASS` — доказано;
- `WARN` — ограничение;
- `FAIL` — обязательное условие не выполнено;
- `MANUAL` — нужен тест человеком.

Скрипт не должен печатать необработанные адреса, account identity или ID. Manual tests записываются только allowlisted markers.

## Первый шаг

На Mac mini открой Terminal в корне репозитория. После объяснения и отдельного согласия выполни:

```bash
bash ./mac-mini-24x7/00-preflight/check-system.sh
```

После разбора одного результата открой [00-preflight/runbook.md](00-preflight/runbook.md). Не переходи к обновлению или установке в тот же шаг.

## Критерий завершения

Финальный status выдаётся только фазой 10:

- `secure-ready` — все удалённые каналы проверены после обычного входа, а необходимость локальной FileVault-разблокировки зафиксирована;
- `autonomous-ready` — дополнительно доказаны pre-login/recovery path, reboot, power recovery и headless.

Наличие установленных приложений без end-to-end тестов не является завершением.
