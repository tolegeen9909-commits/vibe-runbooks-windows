# Claude Code instructions

Полностью прочитай и соблюдай корневой AGENTS.md. Он сначала выбирает целевую машину и направляет только в один маршрут.

- Для Windows 11 следуй корневым FOR-CODEX.md, RITUALS.md и INDEX.md.
- Для Mac mini 24/7 следуй mac-mini-24x7/AGENTS.md и документации внутри этой папки.
- Если целевая машина не названа, задай один короткий вопрос.
- Не смешивай команды двух ОС и не запускай все фазы одновременно.
- Перед любой внешней, административной, сетевой, изменяющей систему или труднообратимой операцией дождись отдельного явного подтверждения человека.
